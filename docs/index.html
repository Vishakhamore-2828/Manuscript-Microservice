Book Platform

Manuscript Processing System

Book Platform is an event-driven manuscript processing system designed to handle manuscript submission, validation, beautification, and publishing workflows.

Manuscript Validation

The Manuscript Validation Service validates uploaded manuscripts before they proceed to the next processing stage. Validation includes file type, file size, filename, ISBN, required metadata, file existence, and file integrity checks.

Email Notifications

The system uses Amazon Simple Email Service (Amazon SES) to send transactional email notifications to authors regarding manuscript validation and processing results.

Technology

Java · Spring Boot · MongoDB · AWS S3 · AWS SNS · AWS SQS · Amazon SES · Apache Camel
